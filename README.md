# Picly 📸 — Classroom Security Lab

Versão educacional do **Picly** preparada para uma atividade de segurança.

## O que esta versão faz

- Funciona sem banco de dados.
- Possui contas fictícias prontas.
- Inclui login normal.
- Inclui um fluxo legado propositalmente fraco para simular uma falha de autenticação.
- A simulação é limitada às contas fictícias comuns.
- A conta administrativa não pode ser acessada pelo fluxo vulnerável.
- Nenhum dado real é coletado ou enviado para serviços externos.

## Hospedagem

O arquivo `index.html` é autossuficiente e pode ser publicado diretamente pelo **GitHub Pages**.

No GitHub:

1. Abra **Settings**.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione `main` e `/(root)`.
5. Clique em **Save**.

Depois de alguns instantes o endereço será:

`https://irangeluchoa-jpg.github.io/picly/`

## Uso responsável

Este projeto é um laboratório fictício. O fluxo vulnerável existe apenas para demonstrar conceitos de autenticação em contas de demonstração e não deve ser adaptado para acessar contas ou sistemas de terceiros sem autorização.
